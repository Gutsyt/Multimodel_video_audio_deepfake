## 4. Train the models

The idea in one paragraph: two large pretrained networks (CLIP for faces, XLS-R for speech) stay **frozen**; they turn every face crop or 4-second speech window into a 1024-number "fingerprint" (an *embedding*). A tiny classifier (logistic regression) then learns which fingerprints are real and which are fake. Freezing the big networks is what makes this trainable on a CPU and is what generalises best to new fakes (Ojha et al. CVPR 2023; Pascu et al. Interspeech 2024).

Pick two folders outside the repo (they hold gigabytes):
```bash
export DATA=~/avdd_data CACHE=~/avdd_cache        # PowerShell: $env:DATA="$HOME\avdd_data"; $env:CACHE="$HOME\avdd_cache"
```

### 4.1 Download the data (about 10 GB, 10–40 min)
```bash
python scripts/download_data.py $DATA
```
What it fetches: Celeb-DF/FakeAVCeleb frames, In-the-Wild (all), 2 shards each of ASVspoof 2019 LA and ASVspoof 5, 44 WildDeepfake tars, and 2,020 FaceForensics++ videos (all 1,000 real + 170 per manipulation method), read out of the 18 GB zip with HTTP range requests.

**Success:** last line `DONE`. Re-run it if a download is interrupted; finished files are skipped.

### 4.2 Extract the embeddings (the long step)
Run both; they can run at the same time (in two terminals) or one after the other.

```bash
# CPU: limit threads so two jobs share the cores fairly
export OMP_NUM_THREADS=2                           # PowerShell: $env:OMP_NUM_THREADS=2
python scripts/train_heads.py embed-visual --data $DATA --cache $CACHE             # add --device cuda on a GPU
python scripts/train_heads.py embed-audio  --data $DATA --cache $CACHE             # add --device cuda on a GPU
```

| Job | Items | CPU (4 cores shared) | GPU |
|---|---|---|---|
| `embed-visual` | about 10,500 face crops | about 2.5–3 h | about 5–10 min |
| `embed-audio` | 8,500 speech windows | about 80 min | about 3–5 min |

It prints progress like `vis: 1088 embedded (0.93/s)` and `saved vis_ff 4021` when a source is finished. Outputs, one file per source, all in `$CACHE`:

```
vis_ff.npz  vis_wdf.npz  vis_wdf_test.npz  vis_celeb.npz  vis_celeb_test.npz
aud_ASVspoof2019_LA.npz  aud_ASVspoof5.npz  aud_InTheWild.npz
```

Interrupted? Just re-run the same command: sources whose `.npz` exists are skipped.

Knobs (optional): `--frames 2` (face frames per FF++ video), `--audio-caps "ASVspoof2019_LA=2000,ASVspoof5=2000,InTheWild=4500"`. More data means a better model and a longer run.

### 4.3 Fit, calibrate, set thresholds (2–5 min)
```bash
python scripts/train_heads.py fit --cache $CACHE | tee fit_log.txt
```
For each check it:
1. tries every stored layer × C ∈ {0.01, 0.1, 1} and keeps the best **validation AUC** (printed as `visual layer 16 C 0.1: val auc 0.93…`);
2. fits **Platt calibration**, so the output is a real probability;
3. sets the thresholds on validation data: `t_fake` just above the 98th percentile of genuine scores (at most about 2% of genuine flagged, never below 0.5) and `t_real` at the 90th percentile (about 90% of genuine cleared);
4. measures the test sets and **writes** `src/avdd/assets/visual_head.npz` and `audio_head.npz`.

**Success criteria** (read them in `fit_log.txt`):

| Metric | Face: in-domain test | Face: WildDeepfake | Voice: held-out speakers |
|---|---|---|---|
| AUC | ≥ 0.85 | ≥ 0.75 (hardest set) | ≥ 0.90 |
| `genuine_flagged` | ≤ 0.03 | ≤ 0.05 | ≤ 0.03 |

If a number misses, see section 10, then note it honestly. Do not move thresholds by hand to make a demo pass.

## 5. Measure: held-out files through the real app (about 40 min CPU)

This is the test closest to your original problem ("a genuine video is flagged"). It runs **files**, not embeddings, through the same code the server runs.

```bash
export E2E=~/avdd_e2e
python scripts/build_test_sets.py $DATA $E2E          # makes 383 test files from test-split identities only
mkdir -p e2e_results
python scripts/evaluate_folder.py --real $E2E/A_ff/real  --fake $E2E/A_ff/fake  --json e2e_results/A_ff.json
python scripts/evaluate_folder.py --real $E2E/B_wdf/real --fake $E2E/B_wdf/fake --json e2e_results/B_wdf.json
python scripts/evaluate_folder.py --real $E2E/C_itw/real --fake $E2E/C_itw/fake --json e2e_results/C_itw.json
python scripts/evaluate_folder.py --real $E2E/D_av/real                         --json e2e_results/D_av.json
```

Each run prints one line per file and a summary like
`real: n=60 likely_authentic=51 (85.0%), inconclusive=8 (13.3%), likely_manipulated=1 (1.7%)`.

**What to look at:** `likely_manipulated` on the **real** rows is the false-alarm rate. The target is ≤ 3% (≤ 5% on WildDeepfake). `D_av` is genuine video + genuine speech; it shows the combined rate when both checks run.

**Your own media (the real proof):** put 20+ of your own genuine videos in a folder (phone clips, calls, YouTube downloads you know are real) and run:
```bash
python scripts/evaluate_folder.py --real path/to/my_real_videos --json e2e_results/mine.json
```

## 8. Feature checklist: test every feature

Start the app: `python scripts/run_server.py`, then open http://127.0.0.1:8000. Wait until the header chip says **Models ready**.

Test files you can make yourself:
```bash
ffmpeg -f lavfi -i sine=frequency=300:duration=5 tone.wav                         # audio, no speech
ffmpeg -f lavfi -i testsrc=duration=5:size=320x240:rate=25 -pix_fmt yuv420p noface.mp4   # video, no face
echo "not media" > notes.txt
head -c 20000 some_real_video.mp4 > truncated.mp4                                 # broken file
```
Plus: one genuine video of a person talking (your phone), one image of a face, one known deepfake (for example from `$E2E/A_ff/fake`).

### Verdicts (each must appear correctly)

## 10. Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| App chip says "Models unavailable", capabilities show `head_missing` | training not run yet | run section 4, or copy the two `.npz` files into `src/avdd/assets/` |
| `download_failed` on start | no internet to huggingface.co the first time | connect once; the backbones are cached afterwards (`~/.cache/huggingface`) |
| Embedding job killed / machine freezes | not enough RAM (other apps) | close apps; run the two embed jobs one after the other, not in parallel |
| Very slow embedding | CPU only | use `--device cuda` on a GPU, or Colab; or lower `--frames` / `--audio-caps` |
| `HTTP 429` during download | Hugging Face rate limit | set `HF_TOKEN`, wait, re-run (it resumes) |
| Fit shows low AUC on WildDeepfake only | hardest, most real-world set | expected to be lowest; increase `--wdf-tars` in download and re-embed |
| Genuine files flagged in `evaluate_folder` | domain unlike the training data (for example heavy filters, screen recordings) | add similar genuine clips to training (put them as an extra source) and re-fit; report the files back |
| `ffmpeg not found` | FFmpeg not on PATH | install it; reopen the terminal |
| Frontend shows old UI | stale build | `cd frontend && npm run build`, hard-refresh the browser |
